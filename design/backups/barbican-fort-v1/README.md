# Barbican fortress — original three-gate illustration

Saved before adding the authenticated courtyard and restricted inner area.
`BarbicanFort.astro` is an unchanged copy of the approved first fortress.

To restore this version, replace `src/components/BarbicanFort.astro` with this
component. The shared `ContentArtwork.astro` wrapper already renders it for
`api-boundaries`. This archive is not imported by the site.

Original accessible description in `src/data/artwork.ts`:

> A small fortress with three successive walls. At Parse, a sentry inspects a request document. At Authenticate, a guard checks a traveller's ID. At Authorize, a fingerprint reader checks an access permit before entry to the protected keep. Valid input, proven identity, and permission are separate checks.
